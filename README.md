# SkillMarket – A Micro-Services Marketplace & Skill Exchange Platform

**SkillMarket** is a platform that empowers students, beginners, and independent creators to monetize their skills, exchange knowledge, and collaborate on real-world projects. It brings together people who want to offer services, learn new skills, or find collaborators, all in one place.

The platform combines the flexibility of a freelance marketplace with the collaborative spirit of skill sharing, making opportunities more accessible to everyone.

## Key Features

- **User Authentication:** Secure registration and login for users.
- **Skill-Based Profiles:** Showcase skills, experience, and completed projects.
- **Service Marketplace:** List, discover, and request services across different categories.
- **Skill Exchange:** Exchange services and knowledge without requiring direct monetary payment.
- **Smart Skill Matching:** Connect users with complementary skills and collaboration opportunities.
- **Service Request Management:** Create, track, and manage service requests.
- **Ratings and Reviews:** Build trust through feedback and completed work.
- **User Dashboard:** Manage listed services, requests, and ongoing collaborations.
- **Portfolio Building:** Help users demonstrate practical skills through completed projects.

## Problem Statement

Many students and beginners possess valuable skills but struggle to find clients, gain practical experience, or build a credible portfolio. At the same time, people often need small services but cannot afford professional freelancers.

Traditional freelance platforms can be difficult for beginners to enter because of competition, limited experience, and a lack of established client reviews.

## Our Solution

SkillMarket provides an accessible environment where users can:

- Offer services and earn money.
- Exchange skills without spending money.
- Collaborate on practical projects.
- Build a portfolio through real work.
- Develop professional connections and gain experience.

## Target Users

- College students and beginners
- Freelancers and independent creators

- Content creators

## Getting Started

Follow these steps to run the project locally once the application is configured.

### 1. Clone the Repository

```bash
git clone <YOUR_REPOSITORY_URL>
cd SkillMarket
```

### 2. Install Dependencies

Navigate to the frontend and backend directories and install their dependencies.

```bash
npm install
```

### 3. Configure Environment Variables

Create a `.env` file in the backend directory and add the required configuration.

```env
PORT=5000
DATABASE_URL=your_database_connection_string
JWT_SECRET=your_secret_key
```

Use the variable names required by your actual application. Never commit real credentials or secrets to GitHub.

### 4. Start the Application

Run the backend using the command configured in your `package.json`.

```bash
npm run dev
```

Start the frontend in a separate terminal using its configured development command.
